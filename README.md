# 🎮 Gear Shop

Website bán Gaming Gear như chuột, bàn phím, tai nghe, mousepad và phụ kiện gaming.

## 🛠️ Công nghệ

- ReactJS (Vite)
- JavaScript (ES6+)
- HTML5 / CSS3
- Node.js
- Express.js
- RESTful API
- SQL Database
- Git / GitHub
- Postman

## ✨ Chức năng

### User
- Đăng ký / Đăng nhập
- Xem chi tiết sản phẩm
- Giỏ hàng
- Đặt hàng
- Xem lịch sử đơn hàng

### Admin
- Quản lý sản phẩm
- Dashboard
- Quản lý người dùng
- Quản lý đơn hàng
- Upload hình ảnh sản phẩm
